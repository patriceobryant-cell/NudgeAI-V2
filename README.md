# NudgeAI Version 2

A warm, private relationship companion for remembering the people who matter. Add people, save important dates, explore tailored ideas, schedule reminders, and keep everything in your browser.

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it using `npm run preview`.

## Privacy and data

NudgeAI stores people, reminders, preferences, and completed nudges in `localStorage`. Nothing is sent to a server. Settings includes JSON export/import and a full local-data reset. Browser notifications require permission and are checked while the app is open.
